## 概述

本文旨在通过实例介绍 **Spring MVC** 的基本概念，这是一个基于 **MVC（模型–视图–控制器）** 模式的 Java Web 框架。

Spring MVC 是 **Spring Framework** 生态系统的一部分，为开发健壮且易于管理的 Java Web 应用程序提供了一个结构化的框架。

本课程还将介绍 **Thymeleaf**，这是一个现代且强大的渲染引擎，与 Spring MVC 具有极佳的兼容性。

## 目标受众

本课程面向已 **熟练掌握 Java 语言** 的读者。

**无需具备任何 Web 编程的先备知识**，因为相关概念将循序渐进地进行讲解。
